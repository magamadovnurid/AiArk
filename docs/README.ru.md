# AiArk — переносной архив ИИ-моделей

[English README](../README.md) · [Скачать](https://github.com/magamadovnurid/AiArk/releases) · [Архитектура](ARCHITECTURE.md) · [План развития](ROADMAP.md)

AiArk превращает внешний диск объёмом от 4 ТБ в переносное, проверяемое хранилище ИИ-моделей. Один и тот же диск можно подключать к Windows, macOS и Linux. Приложение определяет характеристики компьютера, показывает подходящие модели, проверяет загрузки и устанавливает системный движок локально — отдельно от диска с моделями.

> [!IMPORTANT]
> AiArk **не форматирует диски автоматически**. Сканирование и предварительный просмотр работают без записи. MVP создаёт только собственную папку `AIARK/` и только после точного подтверждения, привязанного к выбранному физическому диску.

## Что решает проект

- не нужно повторно загружать крупные модели на каждый компьютер;
- модели не занимают внутренний диск ноутбука или рабочей станции;
- видно, подходит ли модель под текущие RAM, GPU и VRAM;
- прерванная загрузка продолжается с уже проверенных частей;
- контрольные суммы защищают от повреждённых и недокачанных файлов;
- исполняемые файлы для macOS, Windows и Linux не смешиваются на ExFAT-диске.

## Что уже работает

| Возможность | Состояние MVP |
|---|---|
| Windows, macOS и Linux | Обнаружение внешних физических дисков и характеристик компьютера |
| Безопасная подготовка | Dry-run, отпечаток диска, повторная проверка перед записью и точное подтверждение |
| Универсальный профиль | Рекомендация GPT + ExFAT + не менее 4 ТБ |
| Каталог моделей | Версионированный manifest с лицензией, размером, URL и SHA-256 |
| Совместимость | Рейтинг моделей по памяти, GPU, ускорителю, ОС и архитектуре |
| Загрузки | Части HTTP Range, повторы, возобновление, checksum и repair |
| Локальный runtime | Подбор и установка `llama.cpp` в папку текущей системы |
| Локальная сеть | Поиск соседних AiArk без удалённого запуска команд |
| Интерфейсы | Минималистичное desktop-приложение и CLI |

Автоматическое форматирование, удалённое выполнение и P2P-передача моделей пока намеренно не реализованы.

## Как скачать

Откройте [GitHub Releases](https://github.com/magamadovnurid/AiArk/releases) и выберите файл:

| Система | Файл |
|---|---|
| Windows x64, установка | `AiArk-Setup-<версия>-win-x64.exe` |
| Windows x64, без установки | `AiArk-Portable-<версия>-win-x64.exe` |
| Mac с Apple Silicon | `AiArk-<версия>-mac-arm64.dmg` |
| Mac с Intel | `AiArk-<версия>-mac-x64.dmg` |
| Linux x64 | `AiArk-<версия>-linux-x86_64.AppImage` |
| Debian/Ubuntu x64 | `AiArk-<версия>-linux-amd64.deb` |

В каждом релизе есть файл `SHA256SUMS.txt` для проверки загрузок.

> [!WARNING]
> Версии `0.x` являются публичным MVP и пока не подписаны сертификатами. macOS Gatekeeper и Windows SmartScreen могут показать предупреждение. Загружайте файлы только из Releases этого репозитория и сверяйте SHA-256.

## Как подготовить диск

Рекомендуемый универсальный профиль:

- объём не менее **4 ТБ**;
- таблица разделов **GUID / GPT**;
- файловая система **ExFAT**;
- том подключён с возможностью записи.

Порядок работы:

1. Подключите внешний диск.
2. Запустите AiArk — если диск один, приложение выберет его автоматически.
3. Посмотрите результат безопасной проверки.
4. Если требуется форматирование, сначала сохраните нужные файлы и выполните операцию вручную в системной утилите.
5. Введите показанную фразу `PREPARE AIARK <отпечаток>`.
6. Нажмите «Создать AiArk».

Приложение откажется продолжать, если выбран внутренний или системный диск, объём меньше 4 ТБ, нет GPT/ExFAT, том доступен только для чтения, диск отключили или его отпечаток изменился.

## Что хранится на диске

```text
AIARK/
├── ark.json                    # идентификатор AiArk и отпечаток диска
├── .aiark/                     # загрузки, проверки и логи
├── manifests/catalog.json      # снимок каталога
├── library/index.json          # установленные и проверенные модели
├── models/
│   ├── gguf/
│   ├── onnx/
│   └── safetensors/
├── datasets/
├── exports/
└── docs/
```

Runtime хранится на компьютере:

- macOS: `~/Library/Application Support/AiArk/runtimes`;
- Windows: `%LOCALAPPDATA%\AiArk\runtimes`;
- Linux: `$XDG_DATA_HOME/aiark/runtimes` или `~/.local/share/aiark/runtimes`.

## Запуск из исходного кода

Потребуется Node.js 20 или новее.

```bash
npm ci
npm run dev
```

Основные проверки и сборка:

```bash
npm run check
npm run dist:dir
npm run dist
```

## CLI

```bash
npm run build

node dist/cli.js scan --json
node dist/cli.js disk preview --disk <disk-id>
node dist/cli.js disk format-preview --disk <disk-id> --json

node dist/cli.js disk prepare \
  --disk <disk-id> \
  --confirm "PREPARE AIARK <fingerprint>"

node dist/cli.js model download <model-id> --ark /path/to/AIARK
node dist/cli.js model verify <model-id> --ark /path/to/AIARK
node dist/cli.js model repair <model-id> --ark /path/to/AIARK

node dist/cli.js runtime plan llama.cpp --json
node dist/cli.js runtime install llama.cpp
node dist/cli.js cluster discover --timeout 2000 --json
```

Для закрытых загрузок Hugging Face передайте `HF_TOKEN` через переменную окружения. AiArk не сохраняет этот токен на диск.

Для уже подготовленного большого диска на macOS доступен дополнительный [сторожевой сервис загрузки](VAULT_WATCHDOG.md): он проверяет подлинность диска и возобновляет только незавершённые публичные файлы после сбоя. Диск он не форматирует.
